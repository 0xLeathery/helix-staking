```

Aesthetic: Premium DeFi / crypto-native. Dark, modern, minimal.
Primary color: Emerald green #10b981
Secondary: Light mint #6ee7b7
Accent: Blue #3b82f6

Surface: Dark zinc #27272a
Mood: Trust, conviction, patience, compounding growth.

Must NOT look: cheap, meme-coin, overly flashy, clip-art-like, or generic.
Must look: institutional-grade, trustworthy, like a protocol that handles real money.
```

```
on a dark background (#18181b). Clean geometric linework, no fills inside the
strands. Subtle glow effect on intersections. The mark should be recognizable
at 32x32 pixels and striking at 512x512. No text in this version.
Style: flat vector, crypto-native, premium DeFi aesthetic.
```

## Tips for Best Results

1. Generate each asset separately for best quality
2. Always include the Brand Context block at the start
3. For vector output, append: "Output as clean vector illustration, no photorealistic elements"
4. For variations, try adding: "Generate 4 variations with slight differences in the helix motif"
5. Use Nano Banana's multi-image composition to feed back your favorite outputs as reference images for consistency across the pack
